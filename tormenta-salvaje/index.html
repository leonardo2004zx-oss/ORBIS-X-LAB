Controles. PC: W A S D caminar · ratón mirar · Shift correr · E interactuar · F linterna · Esc pausa. Celular: joystick izquierdo para caminar, deslizá a la derecha para mirar, botones para correr, interactuar y linterna.

Créditos

Diseño, programación, gráficos y sonido generados por código para este proyecto.

  • Árboles, terreno, texturas, lluvia y relámpagos: generación procedural en tiempo real.
  • Audio: síntesis procedural con Web Audio API (lluvia gota a gota, truenos, viento, pasos). Sin grabaciones de terceros.
  • Motor 3D: Three.js r149 (licencia MIT).
  • Tipografías: Cinzel y Source Sans 3 (Google Fonts, licencia OFL).
